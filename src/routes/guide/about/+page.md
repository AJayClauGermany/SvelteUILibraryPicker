Svelte UI Library Picker helps you **shortlist** a Svelte UI library. It is inspired by the
[UI Libs picker for Vue](https://ui-libs.vercel.app) and is an independent, community project, not
affiliated with any library listed here.

## What you can do here

- **[Libraries](/libraries/)** — filter by Svelte version, styling approach and license.
- **[Components](/components/)** — see which libraries ship a given component, under what name.
- **[Compare](/compare/)** — pick libraries and line their components up, with live previews of their default styles.

## Principles

1. **We are a secondary source.** The official documentation is always the source of truth. Every
   library and every component on this site links to its official docs, and every entry shows the
   date it was last checked.
2. **Comparison, not replacement.** We record *facts* (what exists, what version, what license) and
   short descriptions in our own words. We do not copy documentation prose, API references, code
   samples or assets.
3. **Respect licenses.** We record each library's license and follow it. Previews only *use* a
   library as a normal app would (installed from npm, under its license).
4. **Respect boundaries around AI.** Some maintainers welcome AI tooling, some ask for limits. We
   record what each library says and our contribution rules follow it — see
   [Licenses & AI policy](/guide/licenses-and-ai/).
5. **Neutral.** No rankings, no "best library". Different projects need different trade-offs.
